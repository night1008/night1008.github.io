现在注册谷歌账号的难点，已经不在于“填表”，而在于如何让 Google 的风控系统信任你是一个真实用户。国内手机号本身不是问题，**IP 环境、设备指纹、语言时区的一致性**才是决定注册能否成功的关键。

### 📱 首选方案：手机 Gmail App + 国内手机号

这是目前大多数用户反馈**成功率最高**的路径。手机 App 的信任度通常比网页端高，触发二维码扫码验证的概率低很多。

**关键前提**：让手机“伪装”成一个美国本地用户。

**iPhone 设置**：
*   设置 → 通用 → 语言与地区 → 语言改为 **English (United States)**，地区改为 **United States**。
*   设置 → 通用 → 日期与时间 → 关闭“自动设置” → 时区选 **Los Angeles**。

**注册步骤**：
1.  连接一个**干净的美国住宅 IP**（避免普通机房 VPN），之后不要频繁切换节点。
2.  下载官方 **Gmail App**（不需要美区 Apple ID）。
3.  打开 App → 右上角头像 → 添加账号 → Google → 创建账号 → 选择“个人用途”。
4.  填写姓名（拼音+英文名）、出生日期（务必填 **18 岁以上**）。
5.  到了手机验证页面，选择 **+86**，输入你的国内手机号。验证码通常 1-2 分钟内到达。
6.  辅助邮箱填一个常用的（如 QQ 邮箱），完成注册。

### ⚠️ 注册后必须做的两件事（防封）

新注册的账号有被“秒封”或短时间内封禁的风险，尤其是被系统判定为“批量注册”时。注册成功后**立刻**做以下设置：

1.  **补全安全信息**：进入账号设置，**添加辅助邮箱和辅助手机号**（可以用国内 QQ 邮箱和你的 +86 号码）。这能大幅提升账号稳定性，也是未来找回账号的唯一途径。
2.  **开启两步验证**：建议使用 **Google Authenticator** 应用，比短信验证更稳定。
